# External review digest

This is a status-preserving digest of four external-review source records. It
does not turn a review suggestion into a result: the mathematics and physics
charter still requires a declared arm and named verdict. Links point to the exact
living ledger entry.

## Status key

- **ADOPTED (house)** means the living results ledger records house adoption.
- **PROPOSED ON `sol/present-1`** means a presentation change in this branch;
  it is not house adoption or a scientific verdict.
- **BANKED** appears only where the riff ledger explicitly banks the item.
- **DEFERRED** is an open experiment or paper/house decision, not a scientific
  rejection. A device-specific request may be deferred to the house/device
  without being run or declined as evidence.
