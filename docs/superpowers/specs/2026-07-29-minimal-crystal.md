## Leg A — THE WIDTH FLOOR (cheapest, first)

(lr 1.5e-3/bs8, seed 1, sigma 3.5 known): d48 -> d32 -> d24
(ffn 4x, heads scaled). Find the cliff. Then stack measured
compressions on the floor model: matryoshka joint loss (tier

Record: smallest artifact gating 60-class. EMA ON (the
adopt-candidate rides every birth; its production-schedule
confirmation is cell A0).

## Leg B — THE PROSTHETIC DIET (delegation; Artin: "weights
call an external function")
Weights should not store what the oracle computes. Augment
gen-4 rows with explicit call-spans (`call: gcd(48,36) -> 12`
etc. — axiom/sympy compute the span at farm time; the model
learns to EMIT the call and USE the result). Paired arms at
d64: plain diet vs call-span diet, matched rows. READ:
capability-per-param jumps (or the model ignores the
prosthetic — either is a verdict). Decode-side: calls resolved
by the engine mid-generation (LLMUE machinery; verified, not
trusted). This is the "knows math + explains moves, stores no
trivia" model.

## Leg C — DIET DESCENT (calculate, don't guess)
Fit marginal-value curves: for each level/kind bucket, births
at rows in {25%, 50%, 100%} of current share (d64, 3ep, n=1 +
sigma column) -> fit gate vs log(rows) per bucket -> allocate
the next farm tranche by highest d(gate)/d(rows). Probes ride
free (flips/token rho .883, mass-on-valid). The 650k row count
becomes an input to an allocation equation. Fences: exclude=-
guarded splits (contamination doctrine); diet exposure SHARE
