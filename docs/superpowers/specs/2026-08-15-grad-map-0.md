# GRAD-MAP-0 — gradient/data-worth atlas (desk instrument spec)

Status: SPEC (pre-run). Origin: GPT-nine riff (RIFF-LEDGER
2026-08-15) + round-2 refinements, house fences. No GPU birth; runs
on existing checkpoints. The instrument earns a birth ONLY by
passing the retrodiction gate below.

## Object

A transfer/interference matrix A[i,j] = signature(train family i)
x signature(failure family j), over frozen checkpoints. Rows =
train families (i_heurisch, non-heurisch remainder, sympy atoms,
axiom atoms, stock chains, per-level slices L3-L7). Columns =
failure populations (the 17 L4 gate failures of L4-PLY0-1 first;
per-level failure sets after).

## Pre-registered metric set (fixed BEFORE any retrodiction look)

1. raw gradient cosine (family mean gradient v failure mean
   gradient)
2. Adam-preconditioned cosine (divide by sqrt(v_hat) from the
   checkpoint's optimizer state where available; else disclosed
   proxy from a short replay)
3. gradient norm per family (scale context, not a ranking metric)
4. projection of family mean gradient onto failure mean gradient
5. pairwise interference within family: mean g_i . g_j over row
   pairs (redundancy/conflict)
6. layerwise variants of 1 and 4 (late layers separately — the
   recognition story predicts late-layer concentration)
7. one low-rank random projection (fixed string-seeded matrix) for
   cheap storage of per-row signatures

No metric added or dropped after the first retrodiction number is
seen. If the set fails, the instrument fails; a new set is a new
pre-registration.

## Checkpoints

Frozen exhaust, no retraining: gallery19m_stock_s3.pt,
gallery19m_atoms_s3.pt (ladder), gallery19m_dose7_s3.pt,
gallery19m_{noheur,ctrl3218}_s3.pt. Gradients computed at the
checkpoint (post-training point); disclosed limitation: worth AT
THE END of training is a proxy for worth DURING — name it in every
readout.

## Retrodiction gate (must pass ALL, blind: compute signatures
before looking up which family "should" win)

R1. sympy atoms rank above axiom atoms on the L4-failure column
    (ATOM-DOSE-LADDER-1, L29662).
R2. i_heurisch ranks above the non-heurisch remainder on the
    L4-failure column (RULE-ABLATE-1, L29916). GROUND-TRUTH
    FENCE: that verdict is itself a single-seed 3-solve delta on
    a 24-problem sub-scale, fired at exactly its bar — R2 is a
    DIRECTION target, and passing it inherits no more confidence
    than the datum carries. R1's ground truth (a 4-solve total
    and a 5-solve L4 gap) is the firmer of the two.
R3. The random-3218 datum gets a mechanism: ctrl3218's
    within-family interference/redundancy (metric 5) explains >= 
    part of full-6000 <= ctrl3218 (72 v 70) — i.e. the dropped
    2,782 rows show higher redundancy with the kept mass than the
    kept mass with itself. Directional check, not a threshold.
FAIL any of R1/R2 => instrument dead in this metric set; book the
null honestly.

## Prospective payload (only after the gate passes)

P1. BASICS shaping: score candidate arithmetic/algebra atom
    families against L3/L4 failure columns BEFORE the basics-diet
    birth; the birth then tests the atlas's prediction (first
    prospective use).
P2. Blind shard pick: let the atlas select a 3,218-row shard from
    the 6,000; race against random-3218 at seed 3, matched
    horizon. Bars at its own pre-reg.

## Fences

- Desk instrument; signatures are device-local (Mac); no
  cross-device signature comparisons.
- Never score by weight distance (house law) — everything here is
  gradient-space at a fixed checkpoint, function-adjacent but not
  function-verified; any shard the atlas picks is validated only
  by a birth + gate.
- Failure gradients use teacher-forced loss on failure prompts
  with their booked reference answers — a proxy for "what would
  fix the failure"; disclosed in every readout.
- mps nondeterminism (AMENDMENT SOFT-SPEED-1-PRECONDITION):
  signature computation is forward/backward without optimizer
  steps — verify repeatability of the signatures themselves (two
  passes, cosine of cosines) before trusting any ranking.
