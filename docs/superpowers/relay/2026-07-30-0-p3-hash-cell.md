WHAT P3 IS (one paragraph): a fixed-point twin of the
MicroLM forward. Weights become sigma-law integer codes
(interface tensors emb/head at sigma/8); GEMMs run on the
exact-fp32 integer carrier with hi/lo splitting (every
partial < 2^24, asserted at runtime); RMSNorm is int64
sum-of-squares + integer-Newton isqrt; SiLU / softmax-exp /
RoPE are integer tables generated ONCE and shipped as bytes
— never regenerated per device, since libm variation is
exactly what's being excluded. Determinism holds on any
backend with exact int64 elementwise ops and fp32
multiplies. Reference implementation:
llmopt/decoding/deterministic.py (~190 lines, promoted,
tested); measured price: 96.66% argmax agreement v the fp
model, disagreements concentrated at coin-flip margins.
