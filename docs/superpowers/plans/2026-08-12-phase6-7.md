**Files:**
- Create: `tests/test_zx_engine.py`

**Interfaces:**
- Consumes: `llmopt.search.zx_engine` — `tcount(g)`, `ZXState`,
  `moves(state)`, `macro_moves(state)`, `best_first_zx(g0, budget)`,
  `verify_equal(c_or_g1, g2, qubits)`.

- [ ] **Step 1:** `pytest.importorskip("pyzx")` at module top (same
  optional-dep pattern as the other GPU/toolchain skips — must skip
  cleanly, not error, where pyzx is absent).
- [ ] **Step 2:** Write the failing tests first, then run them to see
  them fail on a stub-free import (they should PASS immediately since
  the engine is booked-working; the point is pinning behavior):
  - `test_tcount_known_circuit`: build a small pyzx circuit with a
    known T-count (e.g. 2 T gates on 2 qubits), assert `tcount` equals
    it after `to_graph()`.
  - `test_best_first_reduces_and_verifies`: random Clifford+T circuit
    (`pyzx.generate.CNOT_HAD_PHASE_circuit`, seeded), run
    `best_first_zx(g, budget=100)`, assert final tcount <= initial AND
    `verify_equal(original, reduced, qubits)` is True. Oracle
    verification, not weight/structure matching — the house rule.
  - `test_moves_are_reversible_states`: `moves()` yields
    `(name, next_state)` pairs whose graphs verify_equal against the
    parent for at least one seeded example (moves are equality-
    preserving rewrites; sample the first 3 to bound runtime).
- [ ] **Step 3:** `pytest tests/test_zx_engine.py -q` green (or all-
  skipped where pyzx missing). Check runtime stays under ~10 s.
- [ ] **Step 4:** Commit `test: zx_engine gets oracle-verified tests
  (spec Phase 6.1)`.
