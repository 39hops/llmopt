## Not done by design

No new vendor download, retraining, recompression, new census, or
kernel research round. The 4,096 one-shot qualification was not
repeated. Power and temperature were not read (powermetrics needs
root); pmset recorded no thermal warning level.

## Lessons

- Filter GitHub Actions runs by the FULL commit sha: gh run list
  --commit with a short sha returns an empty list and a watcher loops
  forever in silence.
- np.asarray on an MLX array is a zero-copy view that keeps the device
  buffer alive; compared arrays held across rounds must be host copies
  or they distort the next round's memory readings.
- A cumulative compiled-kernel set witnesses only the first round that
  used each kernel; a per-round dispatch witness needs a per-call
  counter, or a fresh process per arm.
