## Lessons

- Do not write scratch or scripts files while a liverun is live: the
  index hook regenerates scripts/INDEX.md and the live receipt reads
  tree_dirty true (memory note saved).
- The first CI watcher of the session polled the GitHub API in a tight
  loop and exhausted the hourly quota; poll with a sleep of at least a
  minute.
