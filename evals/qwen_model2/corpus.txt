A spanning tree of a connected graph touches every vertex using the
fewest possible edges, and Kruskal's procedure builds one by
admitting edges in order of increasing weight whenever they join
two previously separate components. The union-find structure that
answers those connectivity queries amortizes to nearly constant
time per operation when path compression and union by rank are
combined.

def rotate_matrix(m):
    n = len(m)
    for i in range(n // 2):
        for j in range(i, n - i - 1):
            t = m[i][j]
            m[i][j] = m[n - 1 - j][i]
            m[n - 1 - j][i] = m[n - 1 - i][n - 1 - j]
            m[n - 1 - i][n - 1 - j] = m[j][n - 1 - i]
            m[j][n - 1 - i] = t
    return m

Error-correcting codes add structured redundancy so that a receiver
can locate and repair corrupted symbols without retransmission. A
Hamming code interleaves parity bits at power-of-two positions,
and the pattern of failed parity checks spells out the address of
the flipped bit directly. Reed-Solomon codes instead treat the
message as coefficients of a polynomial evaluated at known points,
so any sufficiently large subset of clean evaluations determines
the original message exactly.

The stack discipline of a call frame mirrors the nesting of the
source program: arguments, return address, and saved registers are
pushed in a fixed order, and unwinding restores the caller's view
without the callee leaving a trace.
