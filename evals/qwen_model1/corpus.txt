The measurement of information content in a signal, formalized by
Shannon, connects the probability of a symbol to the number of bits
required to encode it. Rare events carry more information than
common ones, and the entropy of a source is the expected
information per symbol. Compression algorithms approach this bound
by assigning shorter codes to frequent patterns.

def merge_sorted(a, b):
    out = []
    i = j = 0
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            out.append(a[i]); i += 1
        else:
            out.append(b[j]); j += 1
    return out + a[i:] + b[j:]
